# Evidencia de simulacros

Registros generados por los simulacros de `docs/runbooks/lanzamiento.md` (restauración, PITR, vuelta atrás de migraciones,
despliegue fallido, incidente). Cada archivo lleva su fecha y lo escribe el propio script; no se editan a mano.
Se vuelven a generar antes de cada lanzamiento.
